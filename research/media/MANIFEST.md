# Media manifest: dial-up modem history

Compiled 2026-11-20. Every file here comes from Wikimedia Commons.

**How licenses were verified.** License short name, license URL and author are copied from the Commons API (`prop=imageinfo`, `extmetadata`) for each file, fetched 2026-11-20. For public-domain files the rationale was read from the license template on the file page. Nothing was inferred from search snippets.

**Status.** 28 image files are on disk and listed in full below. Another 28 passed the same license check but were NOT downloaded: Wikimedia's file server began answering HTTP 429 (`retry-after: 600`) and the run was stopped before they were fetched. They are listed in "Verified but not downloaded". No audio file is on disk.

**Integrity.** All 28 are real image files (`file` reports JPEG, PNG, WebP or SVG). The 25 originals match the SHA-1 Commons reports. Nothing was edited or converted.

**Renditions.** Three files exceeded 4 MB, so the downscaled rendition from the API `thumburl` was taken. A 1600 px width was requested; Commons served its nearest standard size, 1920 px wide. The pixel sizes below are measured from the files on disk.

**Audio, in one line.** Commons has dial-up handshake recordings, but only generic ones are freely licensed: `Dial up connection.ogg` (Public domain, pdsounds.org), `Dial up connection (short).oga` (CC0), `Dial up modem noises.ogg` (Public domain, PD-self, with a provenance doubt); recordings labeled by standard exist only for V.34, V.90 and V.92 and are all CC BY-SA 4.0, and nothing was found for Bell 103/V.21, V.22bis or V.32/V.32bis.

**Reading the caveats.** "Trademark only" means a logo is visible but raises no copyright concern for the photo. "CONCERN" marks third-party copyrighted artwork inside the frame. "US-only PD reasoning" means the rationale is a US rule (no copyright notice) and may not hold elsewhere.
